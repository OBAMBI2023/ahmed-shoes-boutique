# AHMED SHOES Boutique

AHMED SHOES — Boutique de chaussures pour femmes

Créer une boutique e-commerce moderne, élégante et responsive, spécialisée dans la vente de chaussures pour femmes.

Nom de l'application : AHMED SHOES

Slogan : « Votre style, votre signature. »

Identité visuelle :

Logo typographique élégant : AHMED SHOES.

Fond blanc cassé, noir profond et touches de rose poudré.

Design premium inspiré de l'image de référence fournie.

Cartes produits arrondies avec de belles photos de chaussures féminines.

Prix affichés en FCFA.

Navigation mobile avec un menu bas flottant comprenant Accueil, Boutique, Favoris, Panier et Profil.

Fonctionnalités : catalogue de chaussures, recherche, filtres par catégorie et pointure, fiches produits, panier fonctionnel, favoris persistants et formulaire de commande de démonstration.

Contraintes techniques : frontend uniquement, sans backend ni base de données. Utiliser React, TypeScript, Tailwind CSS et localStorage pour conserver le panier et les favoris. Aucun paiement réel ni aucune commande prétendument transmise à un serveur.

Le résultat doit ressembler à une véritable boutique de chaussures en ligne, avec une expérience mobile soignée et une interface professionnelle. Utiliser AHMED SHOES sur toutes les pages, dans le logo, le titre du site et les métadonnées.
